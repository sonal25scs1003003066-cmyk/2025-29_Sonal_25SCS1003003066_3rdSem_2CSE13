# Weather Data Analysis and Prediction

AI/ML Internship Project developed by **Sonal** as part of the AI/ML Internship at Codec Technologies Pvt. Ltd.

## 📌 Project Overview
This project analyzes historical weather data and predicts **next-day temperature** using Machine Learning.

## 🔧 Technologies Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Jupyter Notebook

## 🚀 Methodology
1. Data Cleaning & Preprocessing
2. Exploratory Data Analysis
3. Feature Engineering
4. Model Training
5. Model Evaluation

## 🤖 Machine Learning Models
- Linear Regression
- Random Forest Regressor

## 📊 Results

| Model | MAE | RMSE | R² |
|---|---:|---:|---:|
| Linear Regression | 1.294 | 1.649 | 0.974 |
| Random Forest | 1.292 | 1.639 | 0.975 |

## 📁 Project Contents
Includes Python source code, weather datasets, Jupyter Notebook, prediction results, visualizations, internship report, presentation, and certificate.
